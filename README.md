# Terraform AWS EC2 Hosting 🚀

This project uses **Terraform** to provision infrastructure on **AWS**.

## Features

* EC2 Instance
* Security Group
* Public IP & DNS
* Nginx Installation
* Website Hosting
* Terraform Variables

## Commands

```bash id="7rtzw1"
terraform init
terraform plan
terraform apply
terraform destroy
```
